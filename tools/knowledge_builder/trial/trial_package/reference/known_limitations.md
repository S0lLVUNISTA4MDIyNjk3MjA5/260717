# 既知の制約 (Alpha 0.2.0 限定人手試用)

このツールはAlpha(早期評価用)ビルドです。試用にあたって、あらかじめ以下の制約を
理解した上でご利用ください。いずれも設計上の既知の制約であり、試用中に同様の挙動に
気づいても不具合ではありません。

## 入力・読み取りに関する制約

- **OCR機能はありません。** 画像として保存されたPDF(スキャンした紙文書など)は、
  文字として読み取ることができません。テキストとして選択・コピーできるPDFのみ対応します。
- **PDFの表構造の解析には対応していません。** PDF内の表(罫線付きの表など)は、表として
  構造化されず、通常の段落・行として扱われます。
- **PDFの見出し検出は、単一階層・高確度のパターンのみに対応しています。**
  「第N章」「N.N タイトル」のような決まった書式の見出しのみを検出します。
  見出しの入れ子(章の中に節、節の中に項、というような階層構造)には対応していません。
- **Excelの取り込みは、選択したシート単位です。** ブック内の全シートを自動的に
  横断して解析するわけではなく、利用者が選択したシートのみが対象になります。

## 表示に関する制約

- **PDFとExcelとで、同じ項目でもタイトルの表示のされ方が異なる場合があります。**
  PDF由来のNodeはタイトルと本文が同じ文になりますが、Excel由来のNodeはタイトルが
  先頭列の値のみになり、本文は列見出しと値を連結した文になります。

## タグ・Relation Candidateに関する制約

- **初期タグは、共有タグ語彙との完全一致に基づいて付与されます。**
  文章の意味を理解して自動的にタグを推測する機能ではありません。そのため、
  内容的にはタグが付いてもよさそうな項目でも、語彙と完全に一致しない限りタグは
  空のままになります。
- **Relation Candidate(関連候補)は、AIによる意味理解に基づくマッチングではありません。**
  タグの一致状況と、文字列同士の類似度(文字単位のn-gramに基づく類似度)を組み合わせた
  機械的な計算で候補を生成しています。そのため、人が読めば明らかに無関係な項目同士が
  低い信頼度で候補に挙がることや、逆に人が見て明らかに関連する項目が候補から漏れる
  ことがあります。
- **Relation Candidateは「採用が確定した関連」ではありません。** あくまで人が確認するための
  たたき台であり、画面上で「採用」または「却下」を選択するまでは、正式な関連としては
  扱われません。

## 保存データに関する制約

- **保存されるKnowledge JSONは、Alpha 0.2.0時点の評価用フォーマットです。**
  今後の開発によって、保存されるデータの構造が変更される可能性があります。
  試用で保存したJSONファイルを、将来のバージョンでそのまま読み込めることは保証されません。

## この試用そのものについての制約

- 本試用は、限られた2つのケース(PDF x Excel、PDF x PDF)のみを対象とした、
  操作感を確認するための試用です。全ての入力パターン(Trace JSONを含む)や
  大規模な文書を対象とした精度評価ではありません。
- 試用で使用したデータ(train_hvac_*)は、本ツールの試用のために作成した架空の
  技術文書であり、実在の製品・仕様を示すものではありません。
