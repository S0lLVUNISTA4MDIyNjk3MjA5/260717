# Knowledge Builder Tool 限定人手試用パッケージ (Alpha 0.2.0)

## これは何か

これは **限定的な人手試用のためのパッケージ** です。開発中のAlpha版ツールを実際に操作していただき、
「使い勝手」「分かりにくい点」「不自然な変換」「Relation CandidateやKnowledge Graphの印象」を
記録していただくことが目的です。

- **本試用は正式な精度評価や、製品としてのリリース可否を判定するものではありません。**
- あくまで「実際に触ってみた感触」を記録していただくためのものです。
- 「正解を当てる」テストではありません。分かりにくい・使いにくいと感じた点をそのまま記録してください。

所要時間の目安: **30〜60分程度**

## 準備

- 推奨ブラウザ: Google Chrome または Microsoft Edge の最新版
- インターネット接続は不要です。このツールは全てブラウザ内で完結して動作します
  (外部サーバーへの通信は行いません)。
- `knowledge_builder_tool_v0.2.0-alpha.html` をブラウザで直接開いてください
  (ダブルクリックするか、ブラウザに `File > 開く` でこのファイルを指定してください)。

## パッケージの中身

```
trial_package/
  knowledge_builder_tool_v0.2.0-alpha.html   ... 本体ツール(このファイルをブラウザで開く)
  README_TRIAL.md                             ... このファイル
  trial_guide.pdf                             ... 試用の進め方(1〜2ページ)
  trial_feedback.xlsx                         ... フィードバック記入用シート
  case_01_pdf_excel/                          ... ケースA: PDF x Excel の試用データ
  case_02_pdf_pdf/                            ... ケースB: PDF x PDF の試用データ
  reference/                                  ... 運用者向け参考資料(評価者への提示は任意)
```

## 試用する2つのケース

- **ケースA (PDF x Excel)**: 顧客要求仕様書(PDF)と設計レビュー表(Excel)を取り込み、
  関連付けを試します。
- **ケースB (PDF x PDF)**: 顧客要求仕様書(PDF)と購入仕様書(PDF)を取り込み、
  関連付けを試します。

どちらか一方でも、両方でも構いません。両方試す場合は合計30〜60分程度を想定しています。

## 操作の流れ(概要)

詳しい手順は `trial_guide.pdf` にも記載していますが、大まかな流れは次の通りです。

1. `knowledge_builder_tool_v0.2.0-alpha.html` をブラウザで開く
2. 試用するケース(ケースAまたはケースB)を選ぶ
3. 文書A・文書Bの入力方式(PDFまたはExcel)を選ぶ
4. 対応するケースフォルダ内のファイルを指定する
5. PDF/Excelのプレビューを確認する
6. 取り込み(Ingest)を実行する
7. Step 2で、原文・出典・タイトル・タグを確認する
   (タグは初期状態で空のものがありますが、この画面で確認・変更できます)
8. Relation Candidate(関連候補)を生成する
9. 生成された候補のうち3〜5件程度を確認し、承認または却下する
10. Knowledge Graphを表示し、フィルタ機能を試す
11. Knowledgeデータ(JSON)を保存する
12. `trial_feedback.xlsx` に感想を記入する

これは詳細な操作マニュアルではありません。触っていて迷った操作や気になった点があれば、
そのまま `trial_feedback.xlsx` に記録してください。

## 困ったときは

途中で操作が分からなくなったり、エラーが出たりした場合も、無理に解決しようとせず、
「どの画面で」「何をしようとして」「どうなったか」を `trial_feedback.xlsx` にそのまま記録してください。
それ自体が貴重なフィードバックです。
