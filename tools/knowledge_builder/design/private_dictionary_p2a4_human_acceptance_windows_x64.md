# P2-A4 Human Acceptance Manual (Windows x64)

Private Dictionary Application / Matching Integration — 最終受入手順

このmanualは、コードを読まずに画面操作だけでP2-A4の最終受入を確認するためのものです。
所要時間の目安は15〜30分です。

## 0. 前提条件

- **OS**: Windows 10/11 x64
- **Browser**: Google Chrome または Microsoft Edge（いずれもChromiumベースの最新安定版。概ね直近1年以内にリリースされたバージョンであれば問題ありません）
- **対象fixed SHA**: このmanualを渡された際に案内されたcandidate SHA（`git log -1 --oneline`で確認できるコミットハッシュ）を使用してください。異なるSHAでは受入結果が対応しません。
- **使用するファイル**:
  - `tools/knowledge_builder/ui/private_dictionary_candidate_review_ui/index.html`（P2-A3レビュー画面。`server.js`経由で起動）
  - `tools/json_ab_trace_matching_tool_v12.1.15.html`（照合ツール。ブラウザで直接開く）
- **fixture / sample file**: P2-A3画面の「標準サンプルを読み込む」ボタンでリポジトリ同梱のサンプルPDF/Excelを使用します。追加のファイル準備は不要です。
- **インターネットの要否**: P2-A3画面はネットワーク接続不要です（`server.js`はローカル127.0.0.1のみで動作し、外部通信を一切行いません）。照合ツール（matching tool）はGraph表示・Excel出力機能でCDN経由のライブラリ（cytoscape/xlsx）を読み込むため、これらの機能を確認する場合はインターネット接続が必要です。接続できない環境では、Detail表示・Project Pin操作・Snapshot切替確認まではオフラインで実施可能です。
- **ダウンロード先**: ブラウザの既定のダウンロードフォルダ（通常 `Downloads`）にファイルが保存されます。
- **私的ファイルの取扱注意**: このmanualで保存する「レビュー作業を保存」ファイルや「Project設定ファイル」は、内部のレビューメモや辞書内容を含む場合があります。第三者と共有しないでください。確認後は不要であれば削除してください。「共有用レビュー集計」ファイルのみ、共有を前提とした内容です。

## 1. P2-A3 Candidate Review 受入

`server.js` を起動し、案内されたURL（`http://127.0.0.1:<port>/`）をブラウザで開いてください。

| # | 手順 | 確認内容 |
|---|---|---|
| A | P2-A3 Candidate Review画面を開く | 画面が正しく表示され、エラーメッセージが出ていないこと |
| B | 「標準サンプルを読み込む」→「解析開始」を実行 | 解析が完了し、候補一覧が表示されること |
| C | 候補一覧・タブ・filter選択肢を確認 | Alias／Conflict／Canonical等の用語が「日本語（English）」の形式（例: 別名（Alias）、競合（Conflict）、正規語（Canonical））で表示されていること |
| D | 画面右上の3ボタンの文言を確認 | 「レビュー作業を保存」というボタンがあること |
| E | 同上 | 「保存したレビュー作業を読み込んで再開」というボタンがあること |
| F | 同上 | 「共有用レビュー集計をExcel保存」というボタンがあること |
| G | ボタン付近の説明文を読む | 「レビュー作業を保存」「保存したレビュー作業を読み込んで再開」＝**非公開**（作業継続用）、「共有用レビュー集計をExcel保存」＝**共有用**（集計のみ）、という役割の違いが文章で読み取れること |
| H | 候補タブのfilter説明を読む | 「判定」「出典」「Rule」「属性」の各filterが何を絞り込むかの説明文があること |
| I | 出典（Source）・Rule・判定（Decision）・属性（Attribute）の各filterを実際に切り替える | 一覧の表示件数が実際に変化すること（0件になった場合は「該当する候補がありません」等のメッセージが出ること） |
| J | 並び替え（Sort）を操作する | 一覧の並び順が変わること（表示される候補の件数自体は変わらないこと） |
| K | 候補を1件以上「承認」にし、「レビュー作業を保存」を押す | ファイルがダウンロードされ、「レビュー作業を保存しました」等のメッセージが出ること |
| L | 判定を変更してから「保存したレビュー作業を読み込んで再開」を押し、Kで保存したファイルを選択 | 未保存の変更が置き換えられる旨の確認ダイアログが出た後、Kで保存した判定状態に戻ること |
| M | 「共有用レビュー集計をExcel保存」を押す | 確認ダイアログで「共有用集計であり、キーワード・別名・レビューメモ等は含まない」旨が表示され、その後ファイルがダウンロードされること |
| N | Mでダウンロードしたファイルを開く（Excel等） | キーワード・別名の原文・レビューメモ・ファイル名などの**私的な内容が一切含まれていない**こと（件数の集計のみであること） |

## 2. Matching（照合ツール）受入

`tools/json_ab_trace_matching_tool_v12.1.15.html` をブラウザで直接開いてください（ダブルクリック、またはブラウザの「ファイルを開く」）。

| # | 手順 | 確認内容 |
|---|---|---|
| A | matching tool起動 | 画面が表示され、コンソールエラーが出ていないこと（開発者ツールを開ける方は F12 → Console で確認） |
| B | JSON A / JSON Bのサンプルデータを読み込み、照合を実行 | 照合結果一覧が表示されること |
| C | Snapshotの設定状態を確認 | 画面上に「辞書Snapshot」の状態（設定済み／未設定）が表示されること |
| D | Project Pin（Project設定）ファイルを保存 | ファイルがダウンロードされること |
| E | 保存したPin fileを読み込む | ファイルの内容が画面に反映されること |
| F | Eの読込直後、照合セッションへの適用状態を確認 | **読み込んだだけでは**照合セッションへ適用されていないこと（明示的な「適用」操作が別途必要であること） |
| G | 「照合セッションに適用」ボタンを押す | 適用が完了した旨の表示が出ること |
| H | 照合を実行する | 実際に照合結果が生成されること |
| I | 照合結果のDetail画面で辞書照合情報を確認 | 正規語一致・承認済み別名・辞書未登録・辞書競合が区別して表示されていること |
| J | Graph表示を開き、ノードをクリックして詳細を確認（Graph描画に外部ライブラリの読込が必要なため、インターネット接続がある場合のみ） | ノード詳細に辞書照合情報が表示されること |
| K | 「辞書照合根拠」を含むExcelを出力する（外部ライブラリの読込が必要なため、インターネット接続がある場合のみ） | Excelファイルがダウンロードされること |
| L | Kのファイルを実際にMicrosoft Excel（またはLibreOffice Calc等）で開く | 正常に開けること、辞書照合根拠のシートが存在すること |
| M | 照合結果画面でSnapshotの識別情報（Snapshot ID・バージョン等）を確認 | 現在使用しているSnapshotの識別情報が画面上で確認できること |

## 3. Stale / Mismatch 拒否確認（最低1件）

| # | 手順 | 確認内容 |
|---|---|---|
| A | 現在適用しているものとは異なるProject IDまたは異なるSnapshotのPin fileを用意する（別のSnapshotで作成したPin fileを流用する等） | - |
| B | そのPin fileを現在のセッションへ適用しようとする | **適用が拒否される**こと（エラーメッセージが表示され、照合セッションの状態が変わらないこと）。黙って新しいSnapshotに切り替わる（silent rebinding）ことがないこと |

## 4. UX確認（YES/NO記入）

以下について、画面操作を通じた率直な印象をYES/NOで記録してください。

- [ ] 保存（レビュー作業を保存）と共有（共有用レビュー集計）を混同しなかった
- [ ] filterの意味を説明文から理解できた
- [ ] Alias（別名）・Conflict（競合）等の用語が理解できた
- [ ] Pin fileの「読込（Load）」と「適用（Apply）」の違いが理解できた
- [ ] provenance表示から、どのSnapshotを使って照合したか確認できた
- [ ] エラーが出た際、何をすればよいか概ね見当がついた

## 6. 注意事項

- このmanualはP2-A4の**人間による最終受入**を目的としたものであり、この受入結果をもって開発者が自動的にrelease/merge/tag等を行うことはありません。
- Graph表示・Excel出力の確認がオフライン環境でできなかった場合は、その旨を「Findings」欄に記録してください（BLOCKING/MAJORではなく、環境上の制約として記録することを推奨します）。
- 疑問点や想定外の挙動があれば、再現手順とともに記録してください。
