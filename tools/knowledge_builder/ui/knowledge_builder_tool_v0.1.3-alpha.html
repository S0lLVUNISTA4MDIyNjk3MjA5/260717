Knowledge Data Builder — α0.1.3（早期評価用ビルド）

Knowledge Data Contract 0.1 準拠 / 今回の改善テーマ: Knowledge Graphで文書階層を折りたたみ・表示粒度調整し、粗い粒度で全体傾向を把握しつつ必要な範囲だけ詳細確認・Relation画面へ絞り込めるように（詳細は同梱README参照）

これは限定評価用の動作物です。正式な設計判断・成果物提出には使用しないでください。 評価目的: 文書単位・章節単位・個別項目の3段階でGraphを把握できるか・document/sectionを個別に折りたたみ・展開できるか・ 集約Edgeの件数と採用/未処理/stale内訳を確認できるか・気になる集約範囲からRelation画面へ絞り込めるか・ A/B表示基準を切り替えても対象Edgeが変わらないと理解できるか・折りたたんでも元のNode/Edgeが失われないか。

1. データを読み込む (既存Trace JSON)

既存のPDF/Excelツールが出力した「照合用JSON（trace JSON）」を読み込みます。PDF/Excelファイルそのものは読み込めません。 先に既存ツールでtrace JSONを出力してから、ここへ読み込ませてください。

変換結果に明らかな誤りがある項目だけを修正します。該当する項目がなければ、この画面の作業は完了です。
一覧の各行をKnowledge Nodeと呼びます。

4. ナレッジグラフを確認 (Knowledge Graph)

ノード同士のつながりを図で確認します。初期状態では採用済みの文書間の関連だけを表示し、 未処理候補・文書内の階層関係は非表示です。Nodeをクリックすると接続先が強調表示されます。
「文書内の階層関係も表示」をONにすると、document/section単位で折りたたみ・展開でき、 折りたたんだ範囲の関連は集約線としてまとめて表示されます（元のNode/Edgeは失われません）。
