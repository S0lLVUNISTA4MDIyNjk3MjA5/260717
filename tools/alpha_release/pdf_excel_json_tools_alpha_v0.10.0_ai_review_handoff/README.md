# PDF／Excel → JSON α版 v0.10.0 生成AIレビュー受け渡し

Build date: 2026-07-27

## 今回の変更

PDF版・Excel版とも、STEP 2のJSONを生成AIへ渡し、照合タグとAI確認済情報を安全に戻す機能を追加しました。
既存の表示形式、確認状態、照合タグ、JSON保存、PDF／Excel保存は維持しています。

### 共通のSTEP 2

- 1段目に`JSON表示`、`JSON保存`、`文章表示／表表示`
- 2段目に`確認状態`、`照合タグ`の個別スイッチ
- 3段目に`PDF保存／Excel保存`
- 4段目に生成AI連携
- 5段目にスクロール可能な閲覧専用の結果表示領域
- 初期状態は確認状態・照合タグともに非表示
- 変換前は表示・保存ボタンとスイッチを無効化
- 変換完了時にSTEP 2を自動表示し、PDFは文章、Excelは表を初期表示
- STEP 3を押した場合だけ編集用画面へ移動

### 生成AI連携

- `プロンプトをコピー`: AI入力JSONを添付する場合の指示文をコピー
- `AI入力JSON保存`: 固定ID、内容ハッシュ、原文、タグ辞書を含むJSONを保存
- `プロンプト＋JSONをコピー`: 指示文とJSONを一括でクリップボードへコピー
- `AI回答を取込`: 回答JSONを貼り付けて検証後に反映
- 対象件数、record_id、内容ハッシュ、原文を全件検証
- 照合タグは既存タグへ追記し、既存タグを削除しない
- 人手の`review_status`は変更しない
- `ai_reviewed`、AI確認日時、方式、モデル名、コメントを別項目として保存
- AI取込は全件検証後に一括反映し、部分更新を行わない
- 外部AIサービスへ自動送信しないオフライン受け渡し方式

### PDF版

- STEP 2の`PDF保存`は、現在表示中の文章またはJSONを印刷画面へ渡す
- 文章表示では、現在オンにした確認状態・照合タグを反映
- JSON表示では、現在の表示用JSONを反映
- ブラウザの印刷画面で`PDFに保存`を選択
- 旧詳細閲覧画面のPDF保存ボタンはSTEP 2へ移設

### Excel版

- STEP 2の`Excel保存`は、元列順に近い表を`.xlsx`として直接保存
- 現在オンにした確認状態・照合タグだけを右端列へ追加
- フィルター、先頭行固定、列幅調整を設定
- 旧詳細閲覧ダイアログのExcel保存ボタンはSTEP 2へ移設

## 維持した機能

- 原資料表示／レビューJSON
- JSON表示・JSON保存
- 内容編集、タグ付け、検証、照合用JSON出力
- 作業保存・復旧、プロファイル、比較などの詳細機能
- オフライン用ライブラリとサンプル
