# 既知の制限事項 — V12.2.0-alpha.1

このドキュメントは「未対応の機能」を明記するものであり、「不具合」の一覧ではありません。α版の設計上意図的に対象外としている範囲です。

- 本ツールは**α版**です。
- 自動照合結果は人間による確認が必要であり、**正式な設計判定の唯一の根拠として使用しないでください**。
- 数量値の訂正は**未対応**です。
- property mappingの訂正は**未対応**です。
- interval semanticsの訂正は**未対応**です。
- comparison modeの訂正は**未対応**です。
- 訂正後の下流再計算は**未対応**です。
- review sessionは**ページ再読込で失われます**。
- review sessionの保存・再読込は**未対応**です。
- 複数レビュアーによる監査履歴は**未対応**です。
- 同時編集・共同編集は**未対応**です。
- 入力Schemaが不正な場合はfail closed(処理を進めず停止)します。
- stale(古い)状態のセッションからは正式出力できません。
- identity mismatch(識別子不一致)状態からは正式出力できません。
- 大規模データではブラウザの処理性能の影響を受けます。
- 対応ブラウザ(Chrome/Edge)以外での動作は未検証です。

## 対象範囲の補足

上記のうち「数量値/property mapping/interval semantics/comparison modeの訂正」「訂正後の下流再計算」「review sessionの保存・再読込」「複数レビュアー監査履歴」「同時編集」は、B-4b(レビュー済みprojectionの読み取り専用表示と正式エクスポート)の設計時点から一貫して対象外と定められている機能です。将来必要になった場合は、本α版とは別の変更として設計・実装されます。
