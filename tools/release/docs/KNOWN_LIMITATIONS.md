# 既知の制限事項 — V12.2.0-alpha.1

このドキュメントは「未対応の機能」を明記するものであり、「不具合」の一覧ではありません。α版の設計上意図的に対象外としている範囲です。

- 本ツールは**α版**です。
- 自動照合結果は人間による確認が必要であり、**正式な設計判定の唯一の根拠として使用しないでください**。
- 数量値の訂正は**未対応**です。
- property mappingの訂正は**未対応**です。
- interval semanticsの訂正は**未対応**です。
- comparison modeの訂正は**未対応**です。
- 訂正後の下流再計算は**未対応**です。
- review sessionは**ページ再読込で失われます**。
- review sessionの保存・再読込は**未対応**です。
- 複数レビュアーによる監査履歴は**未対応**です。
- 同時編集・共同編集は**未対応**です。
- 入力Schemaが不正な場合はfail closed(処理を進めず停止)します。
- stale(古い)状態のセッションからは正式出力できません。
- identity mismatch(識別子不一致)状態からは正式出力できません。
- 大規模データではブラウザの処理性能の影響を受けます。
- 辞書Snapshotは、作成済みのファイルを読み込んで使用します。辞書Snapshotが有効でない場合、辞書タグおよび辞書参照列(Nested Selection)の選択は照合結果に反映されません。
- 辞書参照列の選択内容(Selection設定)は、現在のセッションに適用され、専用の設定ファイルとしてのみ保存できます。ページを再読込すると、設定ファイルを読み込み直すまで選択は空に戻ります。
- Human Evaluation(人手評価)は、trace_idを持ち重複しない照合エンジンの対応のみ保存できます。評価は専用ファイル(`human_evaluation.json`)としてのみ保存でき、ページを再読込すると、ファイルを読み込み直すまで空に戻ります。照合結果が未実行・設定変更で古い場合は、新規の評価を保存できません。正解率などの集計指標は表示しません。

## 対象範囲の補足

上記のうち「数量値/property mapping/interval semantics/comparison modeの訂正」「訂正後の下流再計算」「review sessionの保存・再読込」「複数レビュアー監査履歴」「同時編集」は、B-4b(レビュー済みprojectionの読み取り専用表示と正式エクスポート)の設計時点から一貫して対象外と定められている機能です。将来必要になった場合は、本α版とは別の変更として設計・実装されます。

## 実ブラウザ検証

本α版はPlaywright同梱Chromiumで自動検証しています。

実Google Chromeおよび実Microsoft Edgeについては、α版リリース前の個別検証を実施していません。ブラウザ固有のファイル保存、file://制約、表示差異が残る可能性があります。

Chrome／Edgeで次の問題が発生した場合は利用を中止してください。

- HTMLをfile://で起動できない
- ナレッジグラフが表示されない
- JSON／Excelを保存できない
- console errorが発生する
- stale状態でも正式保存できる
- ChromeとEdgeで出力内容が異なる

問題を確認した場合は、同梱の`BROWSER_VALIDATION_REPORT.md`を使って報告してください。
