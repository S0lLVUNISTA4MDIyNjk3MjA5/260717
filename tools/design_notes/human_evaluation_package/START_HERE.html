L3-1 評価版へようこそ

このパッケージは、PDF・Excelの文書を「照合用JSON」に変換し、2つの文書の対応関係を 自動で照合する一連のツールをまとめたものです。製品としての最終版ではなく、 評価・確認のためのビルドです。

この評価版で確認すること

今回のビルドは、Human Evaluationで見つかった複数の指摘（HE Finding）への対応をまとめた Remediation（是正）ビルドです。少なくとも次の点を確認していただくことが目的です。

  • 安全な自動列選択 ― 照合に使う項目（列）の自動選択が、内部管理用の技術情報など 安全でない項目を誤って選ばないこと
  • HE-09/HE-10の誤対応是正 ― PDF/Excelそれぞれの自己照合で、共通見出し （breadcrumb）だけを根拠にした誤対応が解消されていること
  • 共通見出し・短い低識別語による誤対応の抑止 ― 「以上」「以下」のような短く 汎用的な語や、複数項目に共通する見出しだけを根拠にした対応が生じないこと
  • 照合結果一覧の展開表示（Detail edge expand） ― 各行を展開すると、対応先ごとの confidence・方式・照合根拠が確認できること
  • Graphとの対応関係 ― 照合結果一覧の行・展開行が、ナレッジグラフの実際の ノード・エッジと同一の対応関係を指していること
  • 辞書寄与の行単位の説明（per-edge dictionary explainability） ― 個々の対応関係 について、辞書が実際にその対応の決め手になったのか、それとも辞書情報はあるが使われて いないのかを区別して確認できること
  • HE-14/HE-15（辞書Snapshotなし/ありの比較） ― 同じ元データのまま、辞書 Snapshotの設定前後で対応関係がどう変わるかが明確に確認できること
  • Excel出力のJSON A基準／B基準 ― Excel出力した際、A基準・B基準どちらの シートからも同じ対応関係が一貫して確認できること

各項目の具体的な確認手順は Manual/KMS_L3-1_Human_Evaluation_Guide_JA.pdf と Manual/KMS_L3-1_Human_Evaluation_Checklist_JA.csv に記載しています。

基本の流れ

1
文書A（PDFまたはExcel）→ JSON作成
↓
2
文書B（PDFまたはExcel）→ JSON作成
↓
3
（必要に応じて）辞書候補レビュー → Snapshot作成
↓
4
JSON A + JSON B → Matching（照合）

各ツールを開く

📄 01-JSON-Creation/PDF ― PDFからJSONを作る
📊 01-JSON-Creation/Excel ― ExcelからJSONを作る
📚 02-Dictionary-Review ― 辞書候補レビュー（任意）
🔗 04-Matching ― JSON A/BをMatching（照合）する
📁 Samples/L3-1-Human-Evaluation ― 評価用サンプル一式
📖 評価ガイド（PDF）を開く
操作に迷ったら: Manual/KMS_L3-1_Human_Evaluation_Guide_JA.pdf に、実際の画面のスクリーンショット付きで手順を説明しています。まずそちらをご覧ください。
ご協力のお願い: 評価内容は Manual/KMS_L3-1_Human_Evaluation_Checklist_JA.csv に記録してください。「何が改善されたか」「なぜこの結果になったか説明できるか」といった 項目も含まれています。

必要な環境

Webブラウザ（Google Chrome など）だけで動作します。インターネット接続・サーバー起動・ ターミナル操作は、通常の評価作業では必要ありません。（Graph表示・Excel出力の一部機能のみ、 外部ライブラリ読み込みのためインターネット接続が必要な場合があります。詳しくは Manual/KNOWN_LIMITATIONS_L3-1_JA.txt をご覧ください。）
