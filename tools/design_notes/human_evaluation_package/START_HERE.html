Knowledge Matching Suite
L3-1 評価版へようこそ

このパッケージは、PDF・Excelの文書を「照合用JSON」に変換し、2つの文書の対応関係を 自動で照合する一連のツールをまとめたものです。製品としての最終版ではなく、 評価・確認のためのビルドです。

この評価版で確認すること

今回のバージョンでは、「Matching（照合）」ツールが照合に使う項目（列）を自動で選ぶ際に、 安全でない項目（内部管理用の技術情報など）を誤って選んでしまう不具合を修正しました。 この評価版では、その修正が実際に効いているかを、実データで確認していただくことが主な目的です。

基本の流れ

1
文書A（PDFまたはExcel）→ JSON作成
↓
2
文書B（PDFまたはExcel）→ JSON作成
↓
3
（必要に応じて）辞書候補レビュー → Snapshot作成
↓
4
JSON A + JSON B → Matching（照合）

各ツールを開く

📄 01-JSON-Creation/PDF ― PDFからJSONを作る
📊 01-JSON-Creation/Excel ― ExcelからJSONを作る
📚 02-Dictionary-Review ― 辞書候補レビュー（任意）
🔗 04-Matching ― JSON A/BをMatching（照合）する
📁 Samples/L3-1-Human-Evaluation ― 評価用サンプル一式
📖 評価ガイド（PDF）を開く
操作に迷ったら: Manual/KMS_L3-1_Human_Evaluation_Guide_JA.pdf に、実際の画面のスクリーンショット付きで手順を説明しています。まずそちらをご覧ください。
ご協力のお願い: 評価内容は Manual/KMS_L3-1_Human_Evaluation_Checklist_JA.csv に記録してください。「何が改善されたか」「なぜこの結果になったか説明できるか」といった 項目も含まれています。

必要な環境

Webブラウザ（Google Chrome など）だけで動作します。インターネット接続・サーバー起動・ ターミナル操作は、通常の評価作業では必要ありません。（Graph表示・Excel出力の一部機能のみ、 外部ライブラリ読み込みのためインターネット接続が必要な場合があります。詳しくは Manual/KNOWN_LIMITATIONS_L3-1_JA.txt をご覧ください。）
